# 大洋海战 NavalWarfareMod

《大洋海战》是 DroneFlames（0.33）的二战海战题材模组：日本联合舰队 vs 美国太平洋舰队，**纯海洋、无大陆**。

- **双模式**：沙盒模式自由发展——锚泊浮式母港展开全局；对决模式双方各选 1–4 艘战舰单舰队决战，击沉奖励二选一（全舰恢复 / 换舰重生），己方全沉判负、敌方全沉判胜
- **24 个舰级**：战列舰 / 战列巡洋舰 / 重巡 / 轻巡 / 驱逐舰 / 航空母舰 / 护航航母 / 潜艇 / 护卫舰 / 补给舰，日美两方按各自历史舰级区分（大和、长门、金刚、翔鹤…… / 爱荷华、北卡罗来纳、埃塞克斯……）
- **28 种浮式建筑**：浮式母港、浮船坞、炮台平台、防空平台、雷达浮标、油料平台等，全海上展开
- **炮塔系统**：每座炮塔独立旋转、独立目标、独立开火；逐炮桶独立射击与后坐（单桶试射 / 轮射 / 齐射）；主炮 / 副炮 / 防空炮分工，射界按相对方位解算
- **弹道与散布**：弹种（穿甲 / 高爆 / 半穿甲）与散布按距离解算——近距平射、中距弧线、远距吊射，落点在散布椭圆内取样，手动与自动同规
- **舰载机与鱼雷、部位伤害与损管漏水**、海上维修、烟幕与夜战、海况天气、旗舰指挥令等系统俱全
- 从零设计的专属界面：海图桌、舰桥、舰队幕僚、作战海图、船坞总管、后勤航线、指挥与损管面板

## 安装

1. **游戏内导入**：在游戏的模组管理里选择「导入」，选中下载的 `.dfmod` 文件，启用《大洋海战》。
2. **文件夹放入**：把 `.dfmod` 放到手机的 `Download/DroneFlamesMods` 目录，再在游戏内导入/启用。

## 注意事项

- **适配版本**：DroneFlames 0.33 线（现行 0.33.5.44）。
- **跨语言存档不互通**：中文版的存档不能被英文版读取（反之亦然），切换语言后请开新局。
- 对决模式选舰期间游戏时间冻结且舰队无敌，放心挑选。
